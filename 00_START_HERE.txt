================================================================================
EXAMPLE USAGE
================================================================================

Process a Single Requirement:
---
from pipeline import REPipeline

pipeline = REPipeline()
result = pipeline.process_requirement("REQ_001",
    "The system shall authenticate users using OAuth 2.0")

print(f"Status: {result.status.value}")
print(f"Classification: {result.classification_result}")
---

Process Multiple Requirements:
---
requirements = [
    ("REQ_001", "System shall validate email..."),
    ("REQ_002", "Database shall support 1000 users..."),
]
results = pipeline.process_batch(requirements)
---

Load a Dataset:
---
results = pipeline.load_and_process_dataset("PROMISE")
print(f"Processed {len(results)} requirements")
---

================================================================================
TROUBLESHOOTING
================================================================================

Issue: "ModuleNotFoundError"
Solution: pip install -r requirements.txt

Issue: "API key not found"
Solution: export OPENAI_API_KEY="your_key"

Issue: "Low accuracy on my data"
Solution: Fine-tune BERT, improve prompts, collect more examples

Issue: "Slow processing"
Solution: Use ChatGPT instead of GPT-4o, enable caching, batch process

Issue: "High token usage"
Solution: Use BERT for classification (no tokens), implement caching
